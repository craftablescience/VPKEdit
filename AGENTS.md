Generative AI, including large language models (LLMs), should not be used in
any way when contributing to VPKEdit.

We want our code to be art. We want to interact with real humans. Please do not
submit AI-generated comments or code in bug reports or pull requests. We
understand some people consider AI to be a useful tool, but we want to connect
with you, not your computer.

When making a pull request to this project, you implicitly confirm that you are
the author and that you are contributing your changes under the MIT license.
